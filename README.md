# Kyou no Komado

画像とひとこと、自由なメモ欄を残して見返すための小さなアルバムPWAです。

日記、推し活ログ、AIパートナーとのやりとり、画像プロンプト管理、思い出メモなどに使えます。

## 主な機能

- 画像・日付・タイトル・ひとこと・タグ・メモ欄の保存
- お気に入り
- タグ検索
- 月別表示
- バックアップ書き出し / 読み込み
- テーマカラー変更
- メモ欄名の変更
- 一覧からメモ欄だけコピーするボタンのON/OFF
- アプリ内の注意書き・クレジット表示
- PWA対応。スマホのホーム画面に追加できます。

## データ保存について

投稿した内容や画像は、利用している端末・ブラウザ内に保存されます。  
作者や外部サーバーに自動送信される仕組みはありません。

ただし、端末変更、ブラウザ変更、ブラウザデータ削除などで見えなくなることがあります。  
Safariなどのブラウザで開いた場合と、ホーム画面に追加したアプリ版では、保存データが別になる場合があります。  
使う場所を決めてから投稿するか、バックアップを書き出して読み込みで移してください。  
大事なデータは定期的に「バックアップ」からJSONファイルを書き出してください。

## 使い方

1. GitHub Pagesなどで公開する
2. スマホやタブレットでURLを開く
3. ブラウザメニューから「インストール」または「ホーム画面に追加」
4. 右上の＋から小窓を作成

## カスタマイズ

設定から、テーマカラーとメモ欄の名前を変えられます。  
プロンプト置き場として使う場合は、メモ欄名を「プロンプト」にして、一覧コピーボタンをONにすると便利です。
